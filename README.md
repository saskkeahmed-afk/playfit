# PlayFit — بلاي فت

موقع عربي (RTL) يساعد لاعبي الكمبيوتر على معرفة **هل لعبتهم هتشتغل على جهازهم**: مقارنة بالمتطلبات الرسمية، وعدد الفريمات المتوقع كتقدير، وإعدادات مقترحة، مع قاعدة ألعاب وكروت ومعالجات وأدلة.

📌 **ابدأ من هنا:**
- `PROJECT_MAP.md` — هيكل المشروع وشرح كل ملف و«أريد أن أعدّل كذا، أين أذهب؟».
- `docs/DEPLOY.md` — النشر على GitHub وVercel خطوة بخطوة.
- `seo/` — كل ما يخص السيو (قوائم، قوالب، تقرير الفحص).

## التشغيل
```bash
npm install
cp .env.example .env.local
npm run prod       # ⚡ الأسرع للتجربة: يبني ويشغّل نسخة الإنتاج على http://localhost:3000
npm run dev        # للتطوير (بطيء في أول زيارة لكل صفحة — طبيعي)
npm run check      # أنواع + lint + اختبارات (65 اختباراً)
npm run seo:audit -- http://localhost:3131    # فحص السيو والروابط (انظر seo/README.md)
```
> `npm run dev` يبني كل صفحة عند أول زيارة (قياس: 1–12 ثانية)، بينما نسخة الإنتاج ترد في أقل من 50 ملي ثانية.

## ماذا في الداخل
- **56 لعبة** (15 أساسية + 41 مضافة) بمصدر رسمي لكل منها، **132 قطعة عتاد** (61 كرت شاشة + 71 معالجاً، لكل واحدة جدول «أي الألعاب يناسبها»)، **17 قسماً** للألعاب (10 منها يُفهرس لأن فيها 3 ألعاب فأكثر)، **10 أدلة**، **قاموس** من 21 مصطلحاً، RSS، manifest، أيقونات وصورة مشاركة.
- أدوات: فحص الجهاز، حاسبة FPS، مقارنة العتاد، بحث فوري.

## الإعدادات (`.env.local`)
| المتغير | الغرض |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | الدومين الإنتاجي `https://yourdomain.com` — **إجباري للسيو**؛ بدونه لا canonical ولا sitemap ولا RSS |
| `RAWG_API_KEY` | اختياري: صور للألعاب غير الموجودة على Steam |
| `RESEND_API_KEY`, `CONTACT_TO_EMAIL`, `CONTACT_FROM_EMAIL` | اختياري: تفعيل نموذج التواصل |
| `NEXT_PUBLIC_CONTACT_EMAIL` | بريد بديل يظهر عند فشل النموذج |
| `NEXT_PUBLIC_ADS_ENABLED`, `NEXT_PUBLIC_ADSENSE_CLIENT`, `ADS_TXT_LINE` | الإعلانات (معطّلة افتراضياً) — `docs/ADS.md` |

## الحالة الصريحة (اقرأها قبل النشر)
- **تم فحصه فعلاً:** 65 اختباراً + أنواع + lint + بناء إنتاج ناجح، وفحص آلي لـ **221 صفحة و231 رابطاً داخلياً بصفر أخطاء** (`seo/audit-report.md`).
- **لم يُفحص:** المتصفح الحقيقي (موبايل/كمبيوتر)، Lighthouse، تحميل صور Steam، نموذج التواصل مع مزوّد بريد حقيقي، النشر الفعلي.
- **متطلبات الألعاب** منقولة من الذاكرة ومعلّمة «بانتظار المراجعة» — راجعها من الروابط الرسمية.
- **الفريمات** تقدير تقريبي بنموذج داخلي (ثوابته افتراضات) حتى تضيف قياسات حقيقية في `src/data/benchmarks.ts`.
- **صور Steam** ملك لأصحابها؛ راجع الشروط قبل الربح.
- **الاسم PlayFit** اقتراح: تأكد من توفر الدومين وعدم تسجيله كعلامة تجارية لغيرك.
- **الإعلانات:** معطّلة، وشريط الموافقة المبسّط ليس CMP معتمداً.
