# قائمة الإطلاق

## قبل النشر
- [ ] `npm run check` ينجح (أنواع + lint + اختبارات).
- [ ] راجع متطلبات الألعاب من روابطها الرسمية، وغيّر `verification` إلى `verified` بعد المراجعة (`src/data/games.ts` و`games-extra.ts`).
- [ ] تأكد بصرياً من صور الأغلفة (افتح `/games`). صحّح `steamAppId` لأي صورة خاطئة.
- [ ] أكمل الملاحظات الصفراء في `/privacy` و`/terms` و`/cookies` (اسم الجهة، البريد، القانون).
- [ ] اضبط متغيرات البيئة في المنصة: `NEXT_PUBLIC_SITE_URL` (إجباري)، وبريد النموذج، و`NEXT_PUBLIC_CONTACT_EMAIL`.
- [ ] تأكد أنك تملك الاسم والدومين وأنه غير مسجّل كعلامة تجارية لغيرك (PlayFit اسم مقترح فقط).

## يوم النشر
- [ ] افتح `/robots.txt` — يجب أن يعرض `Sitemap: https://دومينك/sitemap.xml`.
- [ ] افتح `/sitemap.xml` — الروابط بدومينك الصحيح.
- [ ] افتح الصفحة الرئيسية → عرض المصدر → تأكد أن `canonical` بدومينك و`og:image` موجودة.
- [ ] جرّب مشاركة الرابط في واتساب/فيسبوك وانظر المعاينة (صورة PlayFit).
- [ ] شغّل `npm run seo:audit` على الدومين الحقيقي: `npm run seo:audit -- https://دومينك` (أخطاء = 0).
- [ ] اختبر النموذج `/contact` وأنه وصلك بريد فعلاً.

## أول أسبوع
- [ ] أضف الموقع إلى Search Console وأرسل الـ sitemap (`02-search-console-bing.md`).
- [ ] اطلب فهرسة الصفحة الرئيسية و5 صفحات ألعاب مهمة (URL Inspection → Request indexing).
- [ ] أضف الموقع إلى Bing Webmaster Tools.
- [ ] شغّل Lighthouse (موبايل) واحفظ النتائج الحقيقية.

## كل شهر
- [ ] راجع تقرير Performance في Search Console: أي استعلامات تأتيك؟ أي صفحات بلا ظهور؟
- [ ] أضف 3–5 ألعاب موثّقة أو دليلاً جديداً (`03-content-plan.md`).
- [ ] أضف قياسات أداء حقيقية (تحسّن دقة الفريمات وتفتح فرص ظهور أكبر).
- [ ] شغّل `npm run seo:audit` وأصلح أي خطأ.
