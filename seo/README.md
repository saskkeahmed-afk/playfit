# فولدر SEO — كل ما تحتاجه لظهور PlayFit في البحث

هذا الفولدر يجمع **كل ما يخص السيو** في مكان واحد: الشرح، القوائم، القوالب، وتقرير الفحص الآلي. الكود الفعلي للسيو موجود داخل `src/` (انظر `07-technical-seo-map.md` لمعرفة مكان كل شيء).

| الملف | ما فيه |
|---|---|
| `01-launch-checklist.md` | قائمة الإطلاق خطوة بخطوة (قبل/يوم/بعد النشر) |
| `02-search-console-bing.md` | ربط Google Search Console وBing وإرسال الـ sitemap |
| `03-content-plan.md` | خطة المحتوى ونوايا البحث وكيف تكتب صفحة تستحق الفهرسة |
| `04-structured-data.md` | البيانات المنظّمة (JSON-LD) الموجودة وكيف تختبرها |
| `05-on-page-rules.md` | قواعد العناوين والأوصاف والعناوين الفرعية والروابط الداخلية |
| `06-promotion.md` | طرق ترويج مشروعة (بدون سبام) |
| `07-technical-seo-map.md` | خريطة تقنية: robots وsitemap وcanonical وnoindex وRSS وmanifest والصور |
| `08-meta-templates.md` | قوالب جاهزة للعناوين والأوصاف عند إضافة صفحات جديدة |
| `09-keyword-ideas.md` | أفكار عبارات بحث (بدون أرقام بحث مختلقة) |
| `audit-report.md` | تقرير آخر فحص آلي لـ 221 صفحة (يُولَّد بالأمر `npm run seo:audit`) |

## الأمر الأهم
بعد أي تعديل كبير شغّل الفحص الآلي:

```bash
npm run build
NEXT_PUBLIC_SITE_URL=http://localhost:3131 npx next start -p 3131 &
npm run seo:audit -- http://localhost:3131
```
يفحص كل صفحة في الـ sitemap (العناوين المكررة، الأوصاف، H1، canonical، JSON-LD، الصور بلا alt، الروابط الداخلية المكسورة…) ويكتب التقرير في `seo/audit-report.md`.

## تنبيه صريح
لا أحد يضمن ترتيباً في جوجل. هذه الإعدادات تزيل العوائق التقنية وتجهّز المحتوى، لكن الظهور يحتاج وقتاً ومحتوى جيداً وروابط حقيقية.
