# قائمة إطلاق SEO

- [ ] اضبط `NEXT_PUBLIC_SITE_URL` وأعد النشر؛ تأكد أن `/sitemap.xml` فيها روابط الدومين الصحيح و`/robots.txt` يشير إليها.
- [ ] Google Search Console: أضف خاصية Domain، وتحقق بسجل DNS TXT، ثم Sitemaps ← أرسل `sitemap.xml`.
- [ ] راقب Pages (الفهرسة) وPerformance (الاستعلامات) أسبوعياً.
- [ ] Bing Webmaster Tools: استورد الموقع من Search Console أو تحقق يدوياً وأرسل الـ sitemap.
- [ ] أضف قياسات حقيقية وراجع متطلبات كل لعبة قبل الإطلاق؛ لا تُنشئ صفحات رقيقة.
- [ ] شغّل Lighthouse على نسخة الإنتاج واحتفظ بالنتائج الفعلية (لم يُجرَ أي تدقيق في هذه النسخة).
- [ ] تحقق من JSON-LD بأداة Rich Results Test (الترميز لا يضمن ظهور نتائج مميزة).
- ملاحظة: صفحات العتاد التي لا ألعاب مرتبطة بها تحمل `noindex` وتُستثنى من الـ sitemap تلقائياً.
- لم يتم أي توثيق أو أرشفة فعلية حتى الآن.
