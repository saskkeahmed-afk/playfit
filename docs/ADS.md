# دليل الإعلانات

الإعلانات **معطّلة افتراضياً** ولا يُحمَّل أي سكربت إعلاني.

## قبل التفعيل
- قدّم الموقع إلى AdSense وانتظر الموافقة. لا تعرض شارة موافقة قبلها.
- الموقع يحتاج محتوى مفيداً أصيلاً. أضف قياسات حقيقية وأدلة جيدة أولاً.
- راجع سياسات Google للناشرين والموافقة. لجمهور EEA/UK استبدل `ConsentAndAds.tsx` بـ CMP معتمد.
- حدّث صفحتي الخصوصية والكوكيز وأكّد الملاحظات الصفراء فيهما.

## التفعيل
1. في البيئة: `NEXT_PUBLIC_ADS_ENABLED=true` و`NEXT_PUBLIC_ADSENSE_CLIENT=ca-pub-XXXXXXXXXXXXXXXX` (معرّفك الحقيقي).
2. معرّفات الوحدات في `src/lib/config.ts` داخل `ADS.slots` (`inContent`, `sidebar`, `footerBanner`).
3. `ADS_TXT_LINE=google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0` ليخدمه `/ads.txt`.
4. أعد النشر.

## قواعد الوضع
`AdSlot` يحجز ارتفاعاً ثابتاً لتقليل CLS، ولا يظهر إن لم تُضبط المعرّفات. لا تضعه فوق أدوات الحاسبة أو داخل نتائج البحث أو قرب أزرار قد تُنقر خطأ. لا نوافذ منبثقة ولا تحديثات تلقائية.
